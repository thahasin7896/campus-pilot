# 🎓 Student Life Manager

Student Life Manager is a simple web application designed to help college students organize their daily academic activities in one place.

## ✨ Features

- 🏠 Dashboard
  - View study materials, classes, tasks and assignments
  - Quick overview of pending activities

- 📚 Study Materials
  - Add study materials
  - Upload PDF files
  - Download saved PDFs
  - Delete materials

- 📅 Timetable
  - Add classes for different days
  - Set start and end times
  - Add classroom details
  - View timetable organized by day

- ✅ Tasks
  - Add daily tasks
  - Set task dates
  - Mark tasks as completed
  - Delete tasks

- 📝 Assignments
  - Add assignments
  - Set deadlines
  - Mark assignments as completed
  - Delete assignments

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Git & GitHub
